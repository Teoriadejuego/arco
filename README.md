# ARCO

Edición 0.11.2-web.1, 2026-11-18.

[SALMER recoge · DOVELA prepara · CLAVE permite consultar](https://teoriadejuego.github.io/arco/).

La web carga recursos públicos compartidos bajo demanda. La lectura de Excel, el cálculo y el descifrado se realizan en el dispositivo. No se suben encuestas ni claves; no se añade almacenamiento persistente de respuestas. GitHub recibe las solicitudes habituales de páginas y recursos.

- SALMER público es una demostración con personas ficticias. El servidor de recogida no se publica aquí.
- DOVELA conserva cuatro pasos, licencia para archivos propios, accesos por ámbito y entrega cifrada.
- CLAVE conserva consulta, redes, comunidades y PDF autorizado con marca de agua. La contraseña del PDF es el nombre de usuario, predecible e independiente de la frase del informe.
- La primera exportación de PDF en la web necesita conexión para cargar el generador. Para trabajar sin conexión usa los HTML completos de [descargas](https://teoriadejuego.github.io/arco/downloads/ARCO-Local.zip).
- Las demostraciones contienen exclusivamente datos simulados. El recorrido acompañado requiere HTTP(S); los HTML descargados permiten trabajar por archivos.

Esta distribución no incluye datos reales, servidores, claves privadas ni licencias operativas. No implica aprobación para recoger datos reales: siguen pendientes revisión externa y aceptación en dispositivos físicos.

Construcción: herramientas/build-all.mjs y herramientas/build-web.mjs en el repositorio local de fuentes. El manifiesto integridad-publicacion.json permite verificar cada archivo publicado. Cada script y estilo web tiene integridad SRI y nombre con huella; los descargables permanecen autocontenidos. Se mantienen contratos, permisos, métodos y normalización.
